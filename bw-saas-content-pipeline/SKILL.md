### 2. Micro-Module Design Standard (8-12 mins)
Structure: Hook (1 min) → Concept (4-5 min) → Application (2-3 min) → Quiz (1-2 min)

**Video Script Template:**
```
## Module: [Title] | Track: [Sub-Brand] | Duration: [X mins]

### HOOK (0:00 - 1:00)
[Open with a provocative question, stat, or case scenario]

### CORE CONCEPT (1:00 - 6:00)
[Explain concept with Indian corporate examples]
[Include 1 BW framework visual — 4C Profiles, Team Compass, D4MR2]

### APPLICATION (6:00 - 9:00)
["Try This Today" prompt]

### KNOWLEDGE CHECK (9:00 - end)
[3-question quiz: 1 MCQ, 1 scenario, 1 reflection]
```

### 3. Course Architecture Per Track
1. Welcome Module (5 min) — Neeraj's intro video
2. 4-6 Core Modules (8-12 min each)
3. Capstone Assessment (20-30 questions)
4. BW Certificate of Completion + LinkedIn badge
5. Action Assignment (real-world task)

### 4. Content Conversion Process
Step 1 — Content Audit: Identify 4-6 discrete, teachable concepts from source material
Step 2 — Learning Objective Rewrite: SMART objectives using Bloom's Taxonomy
Step 3 — Script Writing: Conversational, with Indian corporate examples
Step 4 — Quiz Design: 3 per module, capstone with Answer Key
Step 5 — SCORM Packaging: SCORM 1.2/2004, imsmanifest.xml, completion tracking
